# 04 — Antarmuka Web Ansible Playbooks (internal/web/static)

Type: task
Status: ready-for-agent
Blocked by: 03

## Tujuan

Menambahkan antarmuka web interaktif Ansible Playbooks pada `internal/web/static/index.html` dengan tata letak Side Panel dan Workspace Modal, editor YAML CodeMirror bawaan, dialog eksekusi dengan pemilih Host/Group, penampil log monospace real-time (polling offset 1s), penegakan peringatan Ansible Gate, dan dukungan dwibahasa (ID/EN) tanpa aset CDN eksternal.

## Perubahan

- Navigasi & Struktur di `internal/web/static/index.html`:
  - Entri menu "Ansible" pada Side Panel sejajar dengan Docker, Kubernetes, dan Cloudflare.
  - Bagian `sectionAnsible` dengan banner Ansible Gate: deteksi biner tidak tersedia vs tersedia tapi nonaktif dengan peringatan keamanan dan tombol aktivasi.
- Komponen Antarmuka:
  - Daftar Playbook: kartu/tabel playbook (nama, deskripsi, badge status run terakhir, waktu eksekusi terakhir) dengan aksi Run, Edit, Riwayat, dan Hapus.
  - Editor Playbook (Workspace/Action Dialog): form nama, deskripsi, extra vars JSON bawaan, dan editor CodeMirror terintegrasi mode YAML (`mode/yaml.min.js` lokal).
  - Dialog Eksekusi Run: pemilih target (pencarian Host dan chip Host Group untuk seleksi sekelompok host), pilihan mode (Run, Check, Diff, Syntax), extra vars JSON, tags, skip tags, verbosity (0..3), dan switch become (sudo tanpa password).
  - Viewer Run (Workspace Modal): lencana status run, durasi, tombol Cancel dan Tutup, panel log monospace polling `GET /api/ansible/runs/{id}/log?offset=` setiap 1 detik dengan smart auto-scroll, serta tab Riwayat per playbook.
- Lokalisasi & Sanitasi:
  - Kamus terjemahan dwibahasa (Inggris dan Bahasa Indonesia) untuk seluruh teks/label Ansible.
  - Seluruh string masukan dari server di-escape dengan `escapeHtml`.
- Unit test antarmuka di `internal/web/ansible_ui_test.go`.

## Acceptance

- File `index.html` valid dan aset tetap mandiri airgapped.
- `go test -v ./internal/web/ -run 'Ansible.*UI'` lolos.
