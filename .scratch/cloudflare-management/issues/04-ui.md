# 04 — Antarmuka Web Cloudflare (internal/web/static)

Type: task
Status: ready-for-agent
Blocked by: 03

## Tujuan

Menambahkan antarmuka web interaktif pengelolaan Cloudflare di `internal/web/static/index.html` dengan tata letak Workspace Modal / Side Panel, dukungan dwibahasa (ID/EN), komponen Toast Notification, Action Dialog, dan Confirmation Dialog tanpa dependensi CDN eksternal.

## Perubahan

- Navigasi & Tata Letak:
  - Entri menu "Cloudflare" pada Side Panel / navigasi utama sejajar dengan Docker dan Kubernetes.
  - Tampilan daftar akun Cloudflare dengan aksi Tambah, Ubah, Hapus akun (field token tipe password, tanpa pengisian ulang otomatis dari server).
- Manajemen Zone & Tab Aksi:
  - Tampilan daftar Zone dengan pencarian dan filter cepat (nama, plan, status, name servers).
  - Tab DNS: tabel DNS records, filter tipe record, tombol Tambah/Ubah/Hapus record dengan konfirmasi modal, toggle proxied status.
  - Tab Cache: tombol aksi "Purge Everything" dengan konfirmasi dialog, form "Purge by URL" (textarea baris demi baris, maksimal 30 URL).
  - Tab Settings: form konfigurasi pengaturan zone (SSL mode, always use HTTPS, security level, development mode, min TLS version, automatic HTTPS rewrites) berbasis dropdown pilihan dari `options`.
- i18n & Aksesibilitas:
  - Penambahan kamus terjemahan Bahasa Indonesia dan Bahasa Inggris untuk seluruh label antarmuka Cloudflare.
  - Penggunaan modal dialog dan notifikasi toast bawaan Pantau, tanpa `alert()` / `confirm()` browser.
- Pengujian UI:
  - Test string antarmuka di `internal/web/*_ui_test.go` untuk memastikan markup dan token i18n ada dan valid.

## Acceptance

- File `index.html` valid, aset tetap airgapped (tanpa CDN eksternal baru).
- `go test -v ./internal/web/ -run 'Cloudflare.*UI'` berhasil.
